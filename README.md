# Weather CLI

A simple Python command-line weather application using the OpenWeather API.

## Features

- Search weather by city
- Temperature in Celsius
- Input validation
- API error handling
- API key stored securely in `.env`

## Requirements

- Python 3.x
- `requests`
- `python-dotenv`
- OpenWeather API key

## Installation

Clone the repository:

git clone https://github.com/sunnyshaw8/weather-project.git

Enter the project:

cd weather-project

Install dependencies:

pip install -r requirements.txt

## Setup

Create a `.env` file:

WEATHER_API_KEY=your_api_key_here

Then run:

python weather.py
